# Skills and workflows

Planned definitions (tasks DEV-02, DEV-03). Each will be trialled once on a real task before it is considered done.

| Skill | Responsibility |
|---|---|
| `requirement-analysis` | Turn a requirement into tasks, architecture changes and required resources |
| `code-generation` | Assist with services, models, UI, configuration and tests |
| `test-and-validate` | Run the project tests and report results |
| `troubleshooting` | Analyse approved logs and failures |
| `documentation` | Keep documentation consistent with the code |
| `deployment-prep` | Prepare configuration and commands for human approval |
