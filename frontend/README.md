# frontend/

React + TypeScript (Vite) operations cockpit. **Skeleton:** the page shows the four provenance labels and placeholders for the planned panels (topology, KPIs, cases, research timeline, scenario comparison, Decision Certificate). Real panels arrive with tasks COK-01 to COK-09. Nothing shown here is real data.

Build check: `npm run build` (type-checks with `tsc`, then bundles with Vite). Setup: see `setup.md`.
